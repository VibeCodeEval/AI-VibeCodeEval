# 🧩 문제

## 문제 설명

대규모 분산 인프라 환경에서, 여러 개의 **이동형 처리 유닛**이 네트워크 평면 위를 순환하며 동작하고 있다.
각 유닛은 위치와 상태 값을 가지며, 일정 규칙에 따라 이동하고 상호작용한다.

네트워크 평면은 크기 ( N \times N )의 순환 구조를 가지며, 가장자리를 넘어가면 반대편으로 이어진다.

각 유닛은 다음의 속성을 가진다:

* 위치: ( (r, c) )
* 수치값: ( v )
* 이동 방향: ( d ) (0 이상 7 이하의 정수)
* 이동 속력: ( s )

방향 ( d )는 총 8개의 방향을 의미하며, 각 방향은 45도 단위로 구분된다.

---

## 동작 규칙

### 1. 이동

모든 유닛은 자신의 방향 ( d )로 속력 ( s )만큼 동시에 이동한다.
이때, 경계를 넘어가는 경우 반대편으로 이어진다.

---
### 2. 상호작용

이동 이후, 같은 위치에 두 개 이상의 유닛이 존재하는 경우 다음을 수행한다.

#### 조건 A — 단일 유지

다음 조건을 만족하면 유닛들은 하나로 합쳐진 상태를 유지하며 분리되지 않는다.

* 병합된 유닛들 중 수치값의 최댓값이 전체 평균의 2배를 초과하는 경우

이때:

* 수치값은 합쳐진 총합을 유지한다.
* 속력은 ( \left\lfloor \frac{\text{속력 총합}}{\text{개수}} \right\rfloor ) 로 설정된다.
* 방향은 아래 방식으로 계산된다:

  각 유닛의 방향 ( d_i )를 각도 ( \theta_i = d_i \times \frac{\pi}{4} )로 변환한 뒤,

  [
  X = \sum (v_i \cdot \cos(\theta_i)), \quad
  Y = \sum (v_i \cdot \sin(\theta_i))
  ]

  [
  \theta_{avg} = \mathrm{atan2}(Y, X)
  ]

  이후 ( \theta_{avg} )를 가장 가까운 방향 인덱스(0~7)로 변환한다.

---

#### 조건 B — 분리

조건 A를 만족하지 않는 경우, 유닛들은 4개의 새로운 유닛으로 분리된다.

* 새로운 수치값: ( \gcd(\text{수치값 총합}, \text{개수}) )

* 새로운 속력: ( \left\lfloor \frac{\text{속력 총합}}{\text{개수}} \right\rfloor )

* 새로운 방향:

  * 모든 기존 방향이 짝수이거나 모두 홀수이면: ( {0, 2, 4, 6} )
  * 그렇지 않으면: ( {1, 3, 5, 7} )

---

### 3. 소멸

상호작용 이후, 수치값이 1인 유닛은 즉시 제거된다.

---

## 명령어

총 ( Q )개의 명령이 주어진다.

---

### 1 K

현재 상태에서 위의 동작 규칙을 ( K )번 반복 수행한다.
각 반복은 “이동 → 상호작용 → 소멸” 순서로 이루어진다.

하나의 명령이 수행되는 동안에는 다른 명령이 개입하지 않는다.

---

### 2 R

다음 작업을 순서대로 수행한다:

1. 현재 시점에서 행 ( R )에 존재하는 모든 유닛의 수치값 합을 출력한다.
2. 이후, 해당 행의 모든 유닛에 대해 수치값을 ( \left\lfloor \frac{v}{2} \right\rfloor )로 갱신한다.
3. 갱신 결과 수치값이 0이 된 유닛은 즉시 제거된다.

출력은 감쇠 적용 이전 값을 기준으로 한다.
동일한 행에 대한 명령이 여러 번 주어질 경우, 감쇠는 누적 적용된다.

---

## 입력 형식

* 첫 줄에 세 정수 ( N, M, Q )가 주어진다.
* 다음 ( M )개의 줄에 각 유닛의 초기 상태가 주어진다.
  각 줄은 다섯 정수 ( r, c, v, s, d )로 이루어진다.
* 다음 ( Q )개의 줄에는 명령어가 주어진다.

각 명령어는 다음 두 형태 중 하나이다:

* ( 1 \ K )
* ( 2 \ R )

---

## 출력 형식

각 ( 2 \ R ) 명령어마다, 해당 시점에서의 결과를 한 줄에 하나씩 출력한다.

---

## 제한 사항

* ( 1 \leq N \leq 10^9 )
* ( 0 \leq M \leq 10{,}000 )
* ( 1 \leq Q \leq 100{,}000 )
* ( 1 \leq r, c \leq N )
* ( 1 \leq v \leq 1{,}000 )
* ( 1 \leq s \leq 1{,}000 )
* ( 0 \leq d \leq 7 )
* 초기 상태에서 동일한 위치에 두 개 이상의 유닛이 존재하지 않는다.

---

## 예제 입력

```
5 3 5
1 1 4 1 0
1 3 6 1 4
2 2 3 2 2
2 1
1 1
2 1
2 1
1 1
```

## 예제 출력

```
10
5
2
```
