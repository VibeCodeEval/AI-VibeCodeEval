## 각 단계 요약

| Step | 목표 | 수정/추가 파일 예시 |
|------|------|---------------------|
| 01 | 예시 문제 정의 + State/Enum 확장 | `problem_info.py`, `states.py`, `enums.py` |
| 02 | 제출 시 턴별 평가에서 8→4 의도 매핑·저장 | `turn_evaluator/analysis.py`, EvalTurnState, 턴 로그/DB 메타 |
| 03 | 사용자 지시에 따라 클린 vs 스파게티 응답 | `writer.py`, Writer용 프롬프트/YAML |
| 04 | 제출 코드에 대해 CC·AST·5대 루브릭 평가 | `integrated_evaluator.py`, radon·AST 유틸 |
| 05 | 새 State 필드 사용, 최종 점수에 v2.1 반영 | `graph.py`, `scores.py`, 필요 시 `states.py` |
| 06 | (수정 프롬프트, CC, AST) 수집 파이프라인 | `scripts/` 또는 `.maestro` 하위 스크립트 |

---

## 사용 방법

1. **Step 01**부터 순서대로 진행한다.
2. 각 Step은 **해당 지시문만** 열어서, 그 안의 “수정 파일·입출력·체크리스트”만 따르면 된다.
3. 선행 Step이 완료되었다고 가정하고 작성되어 있으므로, 이전 Step 완료 후 다음 AI에게 해당 Step 지시문을 전달하면 된다.
